# brimzogames.github.io

Studio site for my mobile games, published with GitHub Pages at
https://brimzogames.github.io/

Each game gets its own folder (e.g. `neon-orbit/`) holding its privacy policy — the URL Google Play and
AdMob ask for. To add a new game: copy `neon-orbit/` to a new folder, edit the policy text for that game,
and add a card for it in `index.html`.
